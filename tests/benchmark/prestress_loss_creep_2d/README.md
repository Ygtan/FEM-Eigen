# σl6 收缩徐变附录 C 显式表值 benchmark（第 34 项 CTest）

第二十三次 B4 · σl6 规范口径收口，opt-in 默认零污染。验证入口：

```
example_mixed.exe --loss-detail-only <file>.dat   →  <file>.dat.loss.txt
loss_probe_3d.exe <file>.dat [out.csv]            →  S,<stage>,<beam>,<KEY>,<value>
```

## 口径（用户 2026-11-16 拍板）

σl6 的表值由用户在模型里**显式录入经核对的规范表值**，程序只按解析发展公式
组装 εcs(t,t0)/φ(t,t0)，**绝不调用 code_loads.hpp 的拟合值兜底**；区分
「显式声明不参与」与「缺值报错」，默认 ECS/PHI 直给路径逐位不变。

| 路径 | 开关 | 行为 | C_SOURCE |
|---|---|---|---|
| 默认 | 无 | σl6=0.9(Ep·ECS+αEP·σpc6·φ)/(1+15ρρps)，ECS/PHI 用户直给 | 不输出(0) |
| 显式不参与 | `C_SKIP=1` | σl6=0，不报错，区别于缺值 | 2 |
| 附录 C 表值 | `C2D=1` | 表值 EPS0/PHI0 + 发展公式算 εcs/φ | 1 |

### 附录 C 显式表值键（`C2D=1` 时全部必填，缺一 throw）

- `EPS0`：名义收缩系数 εcs0（表 C.1.2，C50 及以上已由用户乘 32.4/fck）
- `PHI0`：名义徐变系数 φ0（表 C.2.2，C50 及以上已由用户乘 32.4/fck）
- `C_RH`：环境年平均相对湿度 RH（%），40≤RH<99
- `C_H`：构件理论厚度 h=2A/u（mm）
- `C_T0` / `C_TS` / `C_T`：加载龄期 / 收缩开始龄期 / 计算龄期（d），须 t>t0≥ts

程序按 JTG 3362-2018 附录 C 解析发展公式计算：

```
βs(t,ts)   = [(t−ts)/(350(h/100)² + (t−ts))]^0.5          (C.1.1-5)
εcs(t,t0)  = εcs0[βs(t,ts) − βs(t0,ts)]                    (C.1.3)
RHrep      = 55 若 RH<70，否则 80                          (C.2.3-1)
βH         = min(150[1+(1.2·RHrep/100)^18](h/100)+250,1500)(C.2.1-7)
βc(t,t0)   = [(t−t0)/(βH + (t−t0))]^0.3                    (C.2.1-6)
φ(t,t0)    = φ0·βc(t,t0)                                   (C.2.1-1)
σl6        = 0.9[Ep·εcs + αEP·σpc6·φ]/(1+15ρ·ρps)         (6.2.7-1)
```

条文依据：https://jtg-3362.readthedocs.io/zh/latest/FLC.html

## 算例

| 算例 | 说明 |
|---|---|
| `creep_default` | 默认 ECS/PHI 直给，与仓库 verify_prestress_loss.dat 逐字节一致（零污染锚点） |
| `creep_skip` | C_SKIP=1 显式不参与，σl6=0、C_SOURCE=2 |
| `creep_auto` | C2D=1 完整表值，RH=75%→βH 代表值 80%，与规范算例书对拍 |
| `creep_auto_rh55` | C2D=1，RH=55%→代表值 55%，验证 βH 区间切换 |
| `creep_3d` | 与 creep_auto 同参，2D/3D 同值（含附录 C 全部中间量） |
| `creep_noc2d` | 负例：C2D=1 缺 EPS0 → 显式拒绝 |
| `creep_badrh` | 负例：RH=20% 越界 → 显式拒绝 |
| `creep_conflict` | 负例：C2D=1 + C_SKIP=1 语义冲突 → 显式拒绝 |
| `creep_badage` | 负例：t<t0 龄期倒挂 → 显式拒绝 |

### 规范算例书锚点（creep_auto）

C50（fck=32.4，32.4/fck=1.0）、RH=75%、h=320.7mm、t0=7d、ts=3d、t=97d（存梁 90d）：

- βs(t,ts)=0.1595、βs(t0,ts)=0.0333 → εcs=3.91e-5
- βH=961.8（代表值 80%）、βc=0.4783 → φ=1.0475
- σl6≈4.54e7 Pa（45.4 MPa），与规范算例书 ~45MPa 一致

## 验证范围（142 checks）

- 冻结 .dat/.loss.txt/.csv 的 sha256 与 reference 对齐；
- 当前二进制逐字节重放冻结证据；
- 每条正常算例逐键对齐独立 Python 闭式 oracle（§6.2 + 附录 C，不调用求解器）；
- φ=φ0·βc、εcs=εcs0(βs−βs0) 交叉、βH 两区间代表值切换；
- 四个负例显式拒绝（缺表值 / RH 越界 / 语义冲突 / 龄期倒挂）；
- 默认路径零污染（与既有验证算例逐字节一致且无新字段）；
- C_SKIP 与缺值报错严格区分；
- 2D/3D 同参同值（σl6 与全部附录 C 中间量）；
- loss_probe_3d 只读内核、不自带规范拟合。

## 如实边界

- 表值 εcs0/φ0 由用户录入，程序不查表、不按龄期从 RH/h/fcm 拟合——这是口径选择，
  不是能力缺陷；C50 以上 32.4/fck 折减也由用户体现在录入表值里。
- 只给代表截面的 σl6 标量，不输出 εcs(x)/φ(x) 沿构件分布。
- 不接真实制造参数、不做 ANSYS 对拍；σl6 是后期损失，不进 σpe 与 Pe。
- 不把 B4 整项涂成 `Y`——σl2 / σl6 两项各自收口仍需能力与文档整体评估。
