唯一数据源: BridgeStudio.suspension_3d.build_suspension_3d(
  SYSTEM=EARTH, {'main_span': 120.0, 'side_span': 40.0, 'sag_ratio': 0.1, 'panel': 10.0, 'clearance': 5.0, 'tower_below': 6.0, 'n_tower_seg': 4, 'B': 12.0, 'h': 3.0, 'tf': 0.028, 'tw': 0.02, 'q_deck': 20000.0, 'cable_dens': 0.0, 'tower_dens': 2500.0, 'side_hangers': True, 'anchor_offset': 8.0, 'main_area_mm2': 30000.0, 'hanger_area_mm2': 5000.0, 'tower_b': 2.0, 'tower_h': 2.0, 'lane_count': 1})  -> ModelSpec3D
  注: 生成后清空 model.lanes（本算例只做静力成桥态对标，
      不引入车道活载 / 影响线 / 模态；ANSYS 侧无对应荷载）。

体系差异:
  EARTH 地锚式：主缆锚于桥台外侧锚碇（全约束），H 传地基；
                加劲梁端纵向固定，梁不承受 H。
  SELF  自锚式：主缆锚于加劲梁端节点，H 以轴压进入加劲梁；
                纵向约束置于跨中（对称荷载下支反力恒为零）。

FEM 找形: cable_solver.exe FormFinding（*SUSP_BRIDGE SYSTEM=EARTH）
  converged=True, iterations=10, H=3000.0 kN, 主跨矢高=12 m
  closure_err=6.073276e-04 m (= max|[U]|, 位移量级而非迭代残差)
  tension_err=1.028010e-03
  主缆 20 段 + 吊索 17 根 = 37 根 CABLE；索力 199.8 .. 3315.7 kN
  边跨 40.0 m / 全桥 200.0 m / 塔顶 z=17.0 m

链路:
  ModelSpec3D.to_dat()                 -> cb3d11_susp_earth.dat
  cable_solver.exe <stem>.dat          -> cb3d11_susp_earth_cable.txt
    [ERECTED] + [U] -> 设计几何 D（ANSYS 初始几何）
    [CABLE] L0      -> 绝对下料长度 -> INISTATE 初应变 eps=(L_D-L0)/L0
    [U] / [REACTION] / [CABLE] T -> FEM 参考值
  ansys_bridge_susp.design_geometry() + spec_nl_to_apdl()
                                      -> cb3d11_susp_earth_nl.inp
  ANSYS180.exe -b -j cb3d11_susp_earth_nl_ansys -i cb3d11_susp_earth_nl.inp     -> cb3d11_susp_earth_nl_ansys_*.csv
  compare_susp()                       -> cb3d11_susp_earth_nl_compare_report.txt

ANSYS 语义（本机 ANSYS 18.0 实测，探测脚本见
  FEM-Eigen/tests/benchmark/nonlinear_ansys_3d/probes/）:
  BEAM4 + LINK180(KEYOPT(3)=1 tension only, KEYOPT(2)=0) + NLGEOM,ON
  NSUBST,20,100,10 / NEQIT,50；索轴力 = SMISC 1
  R,id,A,ISTRN 的 ISTRN 对 LINK180 无效；初应变必须用
    INISTATE,SET,DTYP,EPEL + INISTATE,DEFINE,<e>,,EPEL,X,eps
  竖直塔柱 BEAM4 用方向节点 K(+Y) 对齐 FEM 局部轴（8 个）
  eps 范围 0.000206625 .. 0.000571733
  ANSYS 日志: 0 error / 2 warning（KEYOPT(3)=1 undocumented，
    两个 CABLE 单元类型各一条，如实保留不隐藏）

口径边界:
  悬索桥 FormFinding 不是斜拉桥的制造线形闭环。[CAMBER]/[ERECTED]
  只是预拱度建议值，不参与 L0 反算；若误把 [ERECTED] 当作 ANSYS
  初始几何，实测位移相对差 0.25（FAIL）。
  cable_dens=0 -> W=0 关闭垂度/Ernst（ANSYS LINK180 无垂度模型）。
  FEM 共转列式索用 Lagrangian 工程应变；ANSYS NLGEOM 用 Almansi
  应变，两者一阶一致、差异 O(eps^2)。BEAM4 不含大转动梁柱效应，
  成桥位移为毫米量级，影响为二阶。
  未验证：带索垂度 / Ernst 的成桥态对标、大转动下的梁柱效应、
  ANSYS 版本升级后 KEYOPT(3)=1 的行为复测。
