# 结构时变徐变链 vs ANSYS 18.0 CEB90 / 蠕变选项 —— 对拍可行性评估

> 评估时间：2026-11-17。目的：如实判断 FEM-Eigen 的 2D/3D 结构时变徐变链
> 能否与本机 ANSYS 18.0 的混凝土徐变 / 蠕变选项做**同源数值对拍**。
> 结论先行：**不能做本构级同源对拍；可做有限的结构响应级旁证，但需新增
> 伪弹性 APDL 链路且口径无法完全对齐，不建议纳入冻结 benchmark。**

## 1. 本机环境核实（实测）

- 安装存在：`C:\Program Files\ANSYS Inc\v180\`（另有 v170），环境变量
  `ANSYS180_DIR` / `AWP_ROOT180` 齐全，`ANSYS\bin\winx64\ANSYS.exe` 在档。
- 即 **ANSYS 18.0 Mechanical APDL 本机可用**，具备批处理跑 `.inp` 的条件
  （此前 20+ 个 ANSYS benchmark 的黄金值即由它产出）。

## 2. 两侧徐变模型口径对比（核心结论）

| 维度 | FEM-Eigen 结构时变链 | ANSYS 18.0 Mechanical APDL |
|---|---|---|
| 徐变本构 | JTG 3362-2018 附录 C **经验公式** `φ(t,t0)=φ0[(t−t0)/(βH+t−t0)]^0.3`，φ0=φRH·βF·βT0 | `TB,CREEP` 的**隐式/显式蠕变**本构：Norton、time/strain hardening、Garofalo、Anand、广义幂律等（面向金属/高温蠕变） |
| βH / χ 老化系数 | βH 用实际 RH 连续值；AEMM 老化系数 χ=0.8（**固定**） | ANSYS 内置蠕变**没有 χ 老化系数概念**，也没有 βH、φ0、φRH 这些参数 |
| 收缩 | JTG 3362 附录 C `εcs0=εS·βRH`、`βs(t,ts)` | 无内建同龄期混凝土收缩；靠等效初应变 / 用户子程序 |
| 时间积分 | 逐阶段 `Δφ=φ(t)−φ(t_prev)`，模量从 `baseModulus` 按 `E/(1+χΔφ)` 重算（非累乘），按上一阶段轴力施加等效荷载 | 隐式蠕变按本构方程增量积分蠕变应变；显式蠕变按时间步递推——**状态变量/算法完全不同** |
| 混凝土专用 | JTG 3362 是为混凝土桥梁写的 | APDL 的 `TB,CREEP` 主要是金属蠕变；**没有内建 CEB-FIP 1990 / JTG 3362 混凝土时变徐变材料卡** |

**根本障碍**：两侧不是同一个本构。FEM 侧是「按规范经验公式直接算 φ(t) + AEMM
折减模量」；ANSYS 侧是「应力/温度/时间驱动的蠕变应变率积分」。φ0、βH、χ
在 ANSYS 内置蠕变卡里**没有对应参数**，无法同参同值喂进去。中文文献对此的
通行做法（如华东交通大学学报、公路交通科技相关论文）是用 APDL **二次开发**
把 AEMM 转成"伪弹性"分析——即把规范 φ(t) 公式在 APDL 里重算一遍，逐阶段改
`MP,EX` 等效模量——这本质是**把 FEM 的公式搬到 ANSYS 里再算**，验证的是
ANSYS 求解器对给定模量序列的响应，而非两套独立徐变本构的对拍。

## 3. 同源导出链路现状

- BridgeStudio 的 APDL 导出模块（`ansys_bridge*.py` 等 10 个）**没有任何一处**
  写 `TB,CREEP` / `TB,CONCR` 混凝土徐变材料卡；全仓搜索 `TB,CREEP` 零命中。
- `*CREEP_MODEL MODEL=JTG3362 RH= H= FCM= T0=` 只写进 FEM 的 `.dat`
  （`bridge_spec.py:893`、`model_spec_3d.py:822`），ANSYS `.inp` 不含徐变定义。
- 已有 ANSYS 对拍 benchmark 全部是**静力/几何非线性/索找形/屈曲**（BEAM3、
  BEAM4、BEAM188、LINK180、ARCLEN、NLGEOM），无一涉及材料时变徐变。

## 4. 可行路径与工作量评估

### 路径 A：本构级同源对拍 —— 不可行

需要 ANSYS 里存在与 JTG 3362 `φ(t,t0)` + χ 老化等价的材料模型；APDL 内置
蠕变没有，须走 UPF `USERCREEP` 自定义子程序（Fortran，需编译链接 ANSYS 可执行）。
即便实现，也只是在 ANSYS 里重演 FEM 的公式，不构成独立 oracle。

### 路径 B：伪弹性结构响应旁证 —— 有限可行，但不建议纳入冻结 benchmark

做法：在 APDL 里按 FEM 的 φ(t) 序列，逐施工阶段用 `MP,EX` 写等效模量
`E/(1+χφ)` 并施加等效徐变荷载，跑静力解，对比阶段末位移/内力。

- 可行性：ANSYS 批处理 + 单元生死已有成熟链路（施工阶段 benchmark），技术上可做。
- 口径损失：ANSYS 侧模量序列来自 FEM 的 φ 公式，等于假设徐变公式正确；
  只能旁证"ANSYS 线弹性求解器 + 给定模量序列"与 FEM 一致，**不验证徐变公式本身**。
- 工作量：中~高。需新增 APDL 逐阶段 `MP,EX` 导出模块、阶段等效荷载换算、
  冻结证据、CTest；且 χ=0.8 是 FEM 固定值，ANSYS 无法独立确认其取值。
- 收益低：φ/εcs/βs/E_eff 已由本 benchmark 的独立闭式 oracle 逐键核对（75/75），
  再叠一层同源 APDL 旁证不增加公式可信度。

### 路径 C：保持 FEM 自洽 + 闭式 oracle（现状）—— 推荐

本 benchmark 已是这条路径：独立 Python 复现 JTG 3362 附录 C 连续拟合，逐键核对
φ0/βH/εcs0 与逐龄期 φ/εcs/βs/E_eff。这是**可复现、不依赖商业许可、口径可审计**
的最强证据。ANSYS 对拍的缺席如实登记，不虚报。

## 5. 结论

1. **ANSYS 18.0 本机可用**，但内置蠕变是金属/通用蠕变本构，与 FEM 的 JTG 3362
   混凝土时变徐变**不是同一本构**，φ0/βH/χ 无对应参数 → **不能做本构级同源对拍**。
2. BridgeStudio APDL 导出**没有徐变材料卡**，同源导出链路不存在，需新建伪弹性
   APDL 分支（路径 B），且只能旁证结构响应、不验证徐变公式。
3. 建议维持路径 C（FEM 自洽 + 闭式 oracle），把 ANSYS 对拍缺口写入边界文档；
   **若将来确需 ANSYS 复核**，优先做路径 B 的单算例旁证并明确标注"非独立 oracle"，
   不纳入冻结 benchmark、不据此宣称"ANSYS 对拍通过"。
4. B4 能力矩阵不因本 benchmark 或本评估改动（仍为 P）。
