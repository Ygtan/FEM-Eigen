工况 8 个：
  cir025    CIRCLE  lambda=0.25   # quarter circle, theta=pi/2
  cir050    CIRCLE  lambda=0.50   # half circle, theta=pi
  cir075    CIRCLE  lambda=0.75   # three-quarter circle, theta=3pi/2
  cir100    CIRCLE  lambda=1.00   # full circle, theta=2pi, tip returns to root
  pd000     PDELTA  lambda=0.00   # no axial force, linear EB baseline
  pd025     PDELTA  lambda=0.25   # P/Pcr=0.25, mild P-Delta
  pd050     PDELTA  lambda=0.50   # P/Pcr=0.50, matches test_3d_nl.cpp beam-column
  pd075     PDELTA  lambda=0.75   # P/Pcr=0.75, strong P-Delta amplification

口径说明：BEAM188 是 Timoshenko 单元，FEM CR 梁是 Euler-Bernoulli。
  PDELTA 组用 KEYOPT(3)=2 三次插值消除剪切锁定、G 提高 1000 倍消除
  剪切柔度；CIRCLE 组为纯弯矩、无横向剪力，保持默认即可。
  诊断数据见 FEM-Eigen/tests/benchmark/beam_nl_ansys_3d/README.md。
