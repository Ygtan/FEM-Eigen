  {'main_span': 80.0, 'side_span': 30.0, 'tower_height': 25.0, 'n_cable': 4, 'panel': 10.0, 'B': 12.0, 'h': 2.5, 'tf': 0.28, 'tw': 0.45, 'tower_b': 3.0, 'tower_h': 3.0, 'q_deck': 50000.0, 'cable_area_mm2': 3000.0, 'cable_dens': 0.0, 'mode': 'COMPLETION', 'method': 'DECK'})  -> ModelSpec3D

FEM 成桥态: MODE=COMPLETION METHOD=DECK, converged=True, iterations=4,
  closure_err=2.005793e-10 m, tension_err=3.529675e-09
  索数 16，索力 423.7 .. 731.1 kN

链路:
  ModelSpec3D.to_dat()              -> cb3d10_completion.dat
  cable_solver.exe <stem>.dat       -> cb3d10_completion_cable.txt
    [ERECTED]  -> ANSYS 初始几何（制造线形）
    [CABLE] L0 -> INISTATE 初应变 eps=(L_ERECTED-L0)/L0
    [U] / [REACTION] -> FEM 参考值
  spec_nl_to_apdl()                 -> cb3d10_completion_nl.inp
  ANSYS180.exe -b -i *.inp          -> _nl_disp/_reac/_link.csv
  compare_nl()                      -> compare_report.txt

ANSYS 语义（本机 v180 实测）:
  LINK180: KEYOPT(3)=1 tension-only, KEYOPT(2)=0；轴力 = SMISC 1
  R,id,A,ISTRN 的 ISTRN 对 LINK180 无效；初应变必须用
    INISTATE,SET,DTYP,EPEL + INISTATE,DEFINE,<e>,,EPEL,X,eps
  竖直/近竖直 BEAM4 用方向节点 K(+Y) 对齐 FEM 局部轴（16 个）
  NLGEOM,ON + NSUBST,20,100,10 + NEQIT,50
  APDL 命令流纯 ASCII；*CFOPEN+*VWRITE 一次写出整个数组

口径边界:
  索自重 W=0 关闭垂度/Ernst（ANSYS LINK180 无垂度模型）。
  FEM 共转列式索用 Lagrangian 工程应变 N=EA/L0*(Ln-L0)；
  ANSYS NLGEOM 用 Almansi 应变，两者一阶一致，差异 O(eps^2)。
  BEAM4 不参与大转动更新，成桥位移为 mm 量级，影响为二阶。
