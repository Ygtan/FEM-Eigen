3D 混合单元算例归档: CB3D04 parabolic arch bridge 3D (BEAM rib/deck + TRUSS hangers)
==============================================================================

模型: 下承式抛物线拱桥 3D：L=60 m / 矢高 12 m，12 根主梁 BEAM + 12 段拱肋 BEAM（X-Z 斜梁）+ 11 根竖向吊杆 TRUSS，q=20 kN/m 节点化；ANSYS BEAM4 + LINK180
唯一数据源: ModelSpec3D (BridgeStudio/model_spec_3d.py)
  build_arch_bridge_3d(**{'span': 60.0, 'n_elem': 12, 'rise': 12.0, 'B': 8.0, 'h': 2.0, 'tw': 0.02, 'tf': 0.025, 'E_deck': 34500000000.0, 'nu': 0.2, 'hanger_area': 0.002, 'E_hanger': 195000000000.0, 'udl_kN': 20.0, 'title': '抛物线拱桥 3D 混合单元（BEAM 拱肋/主梁 + TRUSS 吊杆）'})

链路:
  ModelSpec3D.to_dat(compact=False)   -> cb3d04_arch_bridge.dat   (FEM-Eigen 3D)
  spec_mixed_to_apdl()                 -> cb3d04_arch_bridge.inp  (ANSYS 18.0)
  example_3d_report.exe <stem>.dat    -> cb3d04_arch_bridge.report.txt
  ANSYS180.exe -b -j <job> -i *.inp   -> _disp/_reac/_beam/_link.csv
  compare_mixed()                      -> compare_report.txt

文件清单:
  cb3d04_arch_bridge.dat             前处理输出（FEM-Eigen 3D .dat）
  cb3d04_arch_bridge.model.json      模型快照（ModelSpec3D JSON）
  cb3d04_arch_bridge.inp             ANSYS BEAM4 + LINK180 APDL
  cb3d04_arch_bridge.report.txt      FEM-Eigen 3D 结果（位移 + 混合单元内力）
  cb3d04_arch_bridge_disp/_reac.csv  ANSYS 节点位移 / 反力
  cb3d04_arch_bridge_beam/_link.csv  ANSYS BEAM4 i 端 6 分量 / LINK180 轴力
  cb3d04_arch_bridge_ansys.out       ANSYS 作业日志
  compare_report.txt / manifest.txt / run_log.txt

关键约定（本机 ANSYS v180 实测，见 ansys_probe/link_probe.py, arch_probe.py）:
  X 纵向 / Y 横向 / Z 竖向；竖向荷载 = DOF3(UZ) = ANSYS FZ
  FEM-Eigen 线性 3D 内核把 CABLE/TRUSS 都按 (EA/L)·c⊗c 轴向杆装配,
    不区分只拉不压、不读 L0、无垂度 -> ANSYS LINK180 口径一致
  只受拉 / 悬链线 / Ernst / 索力迭代属 cable_solver.exe 非线性链
  BEAM4: ET,1,BEAM4 + R,1,A,IZZ,IYY,TKZ,TKY,0 + RMORE,0,J,0,0,0,0
         SHEARZ/SHEARY=0 -> Euler-Bernoulli，与 FEM-Eigen 3D 严格一致
  LINK180: ET,2,LINK180 + R,2,A,ISTRN ; 轴力 = SMISC 1
  斜梁局部坐标: 两侧均 ez_ref=global Z -> ey=Z×ex，X-Z 平面斜梁逐位一致
                纯竖直 BEAM 会差 90°，竖向构件一律改用轴向杆
  ETABLE 需按 ESEL,S,TYPE 分组，避免对 LINK180 请求梁的 SMISC 分量
  *CFOPEN + *VWRITE 一次写出整个数组，外面不能再套 *DO
  APDL 命令流必须纯 ASCII（中文标题需转义）
