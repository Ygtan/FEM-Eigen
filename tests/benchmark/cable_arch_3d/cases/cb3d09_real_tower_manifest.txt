3D 真实塔柱斜拉桥算例归档: CB3D09 single-pylon cable-stayed bridge 3D with real vertical tower (BEAM + CABLE)
==============================================================================

模型: 单塔双跨 L=60 m / 12 个主梁 BEAM 单元；竖直塔柱 6 段 BEAM
      （塔高 18 m，塔底固结，塔梁分离）；6 根 CABLE 扇形索；q=20 kN/m 节点化
唯一数据源: ModelSpec3D (ansys_bridge_tower.build_cable_stayed_tower_3d)
  {'span': 60.0, 'n_elem': 12, 'n_tower_seg': 6, 'tower_z': 18.0, 'B': 8.0, 'h': 2.0, 'tw': 0.02, 'tf': 0.025, 'E_deck': 34500000000.0, 'nu': 0.2, 'tower_b': 3.0, 'tower_h': 3.0, 'cable_area': 0.004, 'E_cable': 195000000000.0, 'udl_kN': 20.0, 'title': '独塔斜拉桥 3D 真实塔柱（BEAM 主梁/塔柱 + CABLE 斜拉索）'}

链路:
  ModelSpec3D.to_dat(compact=False)   -> cb3d09_real_tower.dat   (FEM-Eigen 3D)
  spec_mixed_to_apdl()                 -> cb3d09_real_tower.inp  (ANSYS 18.0)
  example_3d_report.exe <stem>.dat    -> cb3d09_real_tower.report.txt
  ANSYS180.exe -b -j <job> -i *.inp   -> _disp/_reac/_beam/_link.csv
  compare_mixed(tower=True)            -> compare_report.txt

关键约定:
  X 纵向 / Y 横向 / Z 竖向；竖向荷载 = DOF3(UZ) = ANSYS FZ
  FEM-Eigen 3D 对竖直梁取 ey=+X / ez=+Y；ANSYS BEAM4 默认 IY/IZ 互换。
  APDL 自动为 6 个纯竖直 BEAM 单元生成方向节点 K(+Y)，
  用 E,I,J,K 定义单元，实测与 FEM 逐位一致、0 warning；K 节点不参与求解。
  FEM-Eigen 内核零改动；无竖直 BEAM 的既有算例 APDL 逐字节不变。
  BEAM4: SHEARZ/SHEARY=0 -> Euler-Bernoulli；LINK180 轴力 = SMISC 1
  线性 3D 内核把 CABLE 按 (EA/L)·c⊗c 装配（不区分只拉不压、不读 L0）
  *CFOPEN + *VWRITE 一次写出整个数组，外面不能再套 *DO
  APDL 命令流必须纯 ASCII

文件清单:
  cb3d09_real_tower.dat                  前处理输出（FEM-Eigen 3D .dat）
  cb3d09_real_tower.model.json           模型快照（ModelSpec3D JSON）
  cb3d09_real_tower.inp                  ANSYS BEAM4 + LINK180 APDL
  cb3d09_real_tower.report.txt           FEM-Eigen 3D 结果
  cb3d09_real_tower_disp/_reac.csv       ANSYS 节点位移 / 反力
  cb3d09_real_tower_beam/_link.csv       ANSYS BEAM4 i 端 6 分量 / LINK180 轴力
  cb3d09_real_tower_ansys.out            ANSYS 作业日志
  compare_report.txt / manifest.txt / run_log.txt
